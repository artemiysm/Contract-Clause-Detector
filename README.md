# Contract Clause Detector

> **Проверяйте договоры за 30 секунд!**  
> Автоматический анализ юридических рисков в договорах для фрилансеров и малого бизнеса. Находит опасные пункты, даёт рекомендации и позволяет скачать исправленную версию.

**Важно**: Сервис не заменяет юридическую консультацию. Рекомендации носят информационный характер.

---

## Возможности

- Поддержка **PDF и DOCX** (до 10 МБ)
- Обнаружение **20+ типов рисков**:
  - Отсутствие аванса
  - Одностороннее расторжение
  - Передача авторских прав без оплаты
  - Нарушение ФЗ-152 (персональные данные)
  - Неопределённые сроки, штрафы только для исполнителя и др.
- Оценка безопасности договора (**0–100 баллов**)
- Скачивание **PDF-отчёта** с анализом
- Генерация **исправленной версии договора** в формате `.docx` с встроенными рекомендациями
- **Полностью локальный режим** — данные не уходят в облако

---

## Технологии

- **Backend**: Python, Flask, `pdfplumber`, `python-docx`, `pdfkit`
- **Frontend**: HTML, Tailwind CSS (через CDN), vanilla JavaScript
- **PDF-движок**: `wkhtmltopdf` (включён в репозиторий для Windows)
- **Анализ**: Rule-based система на основе ГК РФ, ФЗ-152, ТК РФ

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

git clone https://github.com/ваш-логин/contract-clause-detector.git
cd contract-clause-detector
## Установите зависимости
pip install -r requirements.txt

## Запустите сервер
- python app.py

- Откройте в браузере: http://localhost:5001
